# Projet-python-B2
Repo de projet python de début d'année (B2 IN)

## Application météo

Application Tkinter qui affiche la météo du jour et les prévisions sur 7 jours
(données de l'API Open-Meteo, graphique Matplotlib).

### Installation

    pip install requests pillow matplotlib

### Lancement

    python main.py

### Fonctionnalités

- Écran d'accueil : ville, icône météo, température actuelle, min / max du jour
- Écran des prévisions : graphique des températures min / max sur 7 jours
- Flèches pour reculer / avancer de 7 jours
- Fond d'écran et icônes de nuit selon l'heure
- Menu déroulant pour changer de ville
- Icône de la météo pour chacun des 7 jours
